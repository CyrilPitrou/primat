# `primat.config` — configuration and defaults

`PRIMATConfig` turns a params dict into the frozen configuration every other
module reads, validating ranges and flag combinations as it goes. For the
parameters themselves — names, defaults, meanings — see {doc}`../parameters`;
this page documents the object that holds them, its derived properties and
the physical constants it carries.
