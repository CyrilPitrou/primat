# `primat.weak_rates.api` — n↔p weak rates

The n↔p rates that set the neutron fraction at freeze-out, and therefore
`YP`. `ComputeWeakRates`/`RecomputeWeakRates` are where the cache-or-compute
decision is made; {doc}`../howto/weak-rate-cache` covers the fingerprinting
that makes an expensive integration a one-time cost.
