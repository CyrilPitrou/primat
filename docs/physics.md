# Physics manual

primat's physics is described in full in the project's LaTeX manual and the
underlying Physics Reports paper.

- **Physics Reports paper** — Pitrou, Coc, Uzan, Vangioni, *Physics Reports*
  **04** (2018) 005, [arXiv:1801.08023](https://arxiv.org/abs/1801.08023). The
  primary reference for the background thermodynamics, weak rates, and nuclear
  network.
- **LaTeX manual** —
  [`doc/primat_documentation_v0.3.1.pdf`](https://github.com/CyrilPitrou/primat/blob/master/doc/primat_documentation_v0.3.1.pdf)
  in the repository.
